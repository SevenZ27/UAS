# Credit Score interface

Stage three refines the existing Streamlit 1.55 application in Operate mode. Keep the light surface, dark text and red primary action. This is an educational category classifier, not a loan approval or numerical credit score service.

Typography uses the native Streamlit sans with a compact 32 px desktop / 26.4 px mobile title, 20–22.4 px section headings and 16 px inputs. Content is bounded to 1160 px. Desktop separates the grouped form and result panel; below 1000 px they stack, and narrow screens use one input per row. Input fields and actions have 44 px minimum heights. Focus uses a 3 px blue outline, distinct from the red action color.

Tokens in ui/styles.css define ink #22262b, secondary text #505862, accent #b42318, panel #f6f7f9, line #d8dde3 and focus #0756a1. Category selection uses text plus a border, never color alone. A three-category list shows the selected dataset category without an invented gauge or individual confidence. Accuracy bars start at zero and describe the frozen holdout benchmark. Confusion counts include class support through row totals and percentages; semantic tables retain the numbers for assistive technology.

Inputs are text fields with numeric keyboard hints and explicit validation. The previous number widgets could retain an invalid uncommitted draft after reset; they also reset empty inputs to the minimum unless configured for missingness. Removing steppers removes their unnamed controls rather than hiding accessibility violations. Decimal dots and commas are accepted, mixed thousands formatting is rejected, and fractions are never silently truncated into integer counts. Both backends enforce structural/schema rules. The release accepts values outside training reference ranges with a visible warning and expandable feature details, while preserving the original fitted pipeline's clipping. Empty nullable fields remain explicit and generate an imputation warning. Age is required. Monetary labels omit the confusing unit suffix; adjacent guidance retains the unknown-currency limitation. Initial training medians are rounded to two decimals for non-count features, visibly disclosed, and the actual displayed input is submitted. Editing, resetting or switching backend clears stale results. A prediction or error requests focus once; editing does not move focus. Downloads contain the submitted numeric profile, actual response, warnings and model version.

The small trusted ui/accessibility.js adapter supplies a main landmark, Indonesian document language, numeric keyboard hints and the required-age attribute. It never excludes axe findings or hides working controls. One debounced observer reapplies semantics after Streamlit rerenders. Recheck these selectors and remove redundant patches when upgrading the pinned framework. Reduced motion preserves the result/focus change using immediate scrolling and removes optional color transitions.

Scope: local UI, accessibility and evidence visualization. Model artifacts, frozen evaluation protocol, scores and original course archives remain unchanged. Verification uses Playwright CLI / Chromium responsive and touch emulation; these checks do not establish physical iPhone/Safari behavior or formal WCAG certification.
